Bundled 7-Zip command-line binaries
===================================

FightPlanner distributes platform-specific 7-Zip command-line binaries from:
https://www.7-zip.org/

Bundled versions:
- Linux x64: 7-Zip 26.02
- macOS x64/arm64: 7-Zip 25.01
- Windows x86: 7-Zip 22.01

7-Zip is free software. Most of its source code is licensed under the GNU LGPL.
Some components use the BSD 3-clause License. RAR support contains code subject
to the unRAR license restriction. Full license information and source links:
https://www.7-zip.org/license.txt
https://www.7-zip.org/download.html
